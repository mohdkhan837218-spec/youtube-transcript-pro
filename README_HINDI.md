# 🎬 YouTube Transcript Pro — 1-Click Multi-Language Extractor
### हिन्दी & Roman Urdu Guide (आसान स्टेप-बाय-स्टेप तरीका)

Yeh tool aapko YouTube ki kisi bhi video se **Hindi**, **English**, **Urdu** aur **100+ languages** mein **exact timestamps** ke sath transcript **1-click** mein copy karne ki suvidha deta hai.

---

## 🚀 Step 1: Chrome / Edge Browser Mein Extension Kaise Lagayein (Sirf 10 Seconds)

Aapko kisi coding ki zaroorat nahi hai:

1. **Google Chrome** (ya Microsoft Edge / Brave) browser kholein.
2. Address bar (jahan website ka URL likhte hain) mein yeh type karein aur **Enter** dabayein:
   ```text
   chrome://extensions
   ```
   *(Agar Edge browser use kar rahe hain to `edge://extensions` likhein)*
3. Right side mein upar **"Developer mode"** ka ek switch (toggle) hoga, use **ON** kar dein.
4. Left side mein upar **"Load unpacked"** ka button aayega, us par click karein.
5. Ab is folder ko select karein:
   ```text
   C:\Users\mohda\.gemini\antigravity-ide\scratch\youtube-transcript-pro
   ```
   *(Folder select karke "Select Folder" button dabayein)*

**Mubarak ho! 🎉 Extension aapke browser mein active ho chuka hai!**

---

## ⚡ Step 2: YouTube Par 1-Click Transcript Kaise Nikalein

1. YouTube par jaakar koi bhi video play karein (jaise koi tutorial, news, podcast ya lecture).
2. Video ke theek neeche jahan **Like / Share** ka button hota hai, wahan aapko ek naya laal rang ka button dikhega:
   ```text
   [ 📝 Transcript ]
   ```
   *(Screen ke right-bottom corner par bhi ek floating button hamesha rehta hai)*
3. Is button par **1-Click** karein!
4. Ek stylish panel khul jayega:
   - ⚡ **"Copy Timestamps"**: Is button ko dabate hi poora transcript exact time (`[00:15] Namaste dosto...`) ke sath copy ho jayega!
   - 📄 **"Plain Text"**: Agar aapko ChatGPT, Claude ya Gemini mein prompt daalna hai, to yeh bina timestamp wala clean text copy kar dega!
   - 🌐 **"Language Selector"**: Agar video English mein hai, to dropdown se **"Hindi (हिन्दी)"** select karein — yeh video ko Hindi transcript mein translate kar dega!
   - ⏱️ **Interactive Timestamps**: Transcript ke kisi bhi time (jaise `[01:23]`) par click karein, video turant usi second par chali jayegi!
   - 💾 **Download**: Aap ise `.txt` ya `.srt` (video editing subtitles) ke roop mein bhi download kar sakte hain.

Agar aap kisi doosre computer par hain ya extension ke bina chalaana chahte hain:
